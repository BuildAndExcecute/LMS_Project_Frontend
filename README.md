# LMS Project Frontend

## Overview

This is the frontend component of a **Library Management System (LMS)** project. The frontend provides a user-friendly interface for managing library operations, including book catalogs, borrowing systems, user accounts, and library administration features.

## Project Description

The LMS Project Frontend is built to offer a seamless and interactive experience for library patrons and administrators. Users can browse available books, manage their accounts, track borrowed items, and handle library administrative tasks through an intuitive web interface.

## Technology Stack

This project is built using:

- **HTML** - 87.6% (Structure and markup)
- **CSS** - 9.2% (Styling and layout)
- **JavaScript** - 3.2% (Interactivity and functionality)

## Features

- **Book Management** - Browse and search library catalog
- **User Authentication** - Secure login and user account management
- **Borrowing System** - Check out and return books
- **User Dashboard** - View borrowed books and manage profile
- **Admin Panel** - Administrative tools for library management
- **Responsive Design** - Optimized for desktop and mobile devices

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic knowledge of HTML, CSS, and JavaScript

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/BuildAndExcecute/LMS_Project_Frontend.git
   ```

2. Navigate to the project directory:
   ```bash
   cd LMS_Project_Frontend
   ```

3. Open `index.html` in your web browser or use a local development server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (if http-server is installed)
   http-server
   ```

## Usage

- Open the application in your web browser
- Navigate through the library interface using the menu
- Log in with your credentials to access personalized features
- Browse the book catalog and manage your borrowings
- Admins can access additional management features
